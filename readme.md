# Nintendo Switch Library

This is a small vibe coded website cataloguing the nintendo switch games of my local library.
It's basically a glorified spreadsheet, containing howlongtobeat and metacritic data, along with a first-party / third-party distinction.
I vibecoded this with [arena.ai](https://arena.ai/).
8 iterations, ca 1.5h total + 1h github deployment.
Shoutout to [grok 4.5](https://x.ai/news/grok-4-5), [gemini 3.5-flash](https://deepmind.google/models/gemini/flash/) and [GPT 5.6 sol](https://openai.com/index/gpt-5-6/) for doing the best work.
This could probably be oneshot or twoshot by a frontier model and a good enough prompt.
